Star Citizen Space Combat Communication Protocol

Combat Comms Protocol

Viewer mode is default. Admin mode enables inline edits. Admin unlock is convenience-only for a static offline file.

Viewer

How to run

Open index.html directly in your browser. No server or internet connection is required.

Admin mode is a convenience-only lock for a static offline file. It prevents accidental edits but is not secure.

Rules

  • One call = one state.
  • No narration.
  • Silence is correct.
  • Same breath rule (3–5 seconds).
  • Same breath → name optional.
  • Time passes → name required.
  • Category change → name required.
  • Personal state uses speaker name; shared truth never uses speaker name.
  • Remove “Push” entirely (it does not exist).
  • Regroup on: re-center on anchor, can remain engaged or re-engage quickly.
  • Reset: disengage and reset fight state (break contact).
  • Red (PERSONAL): critical health, not necessarily about to die, can be safe but fragile.

Flow diagrams

Target cycle

Target → Looking / Seen → Merging → Effective / Not effective → Red (TARGET) → Splash OR Target out → new Target

Regroup cycle

Regroup on → Distance (optional) → Ready

Threat interrupt

Aggro → Evasive → Low boost → Clear (critical state: Red (PERSONAL))
